# Personas

Used only where they sharpen a requirement. Infrastructure enablers do not
need artificial human-user framing — see `ENABLER:` stories in
[docs/specs/README.md](../specs/README.md).

| Persona | Cares about |
|---|---|
| Platform Engineer | The maintainer; end-to-end reproducibility from Git. |
| Cloud Engineer | OCI resource shape, Free Tier envelope, IAM. |
| DevSecOps Engineer | CI gates, supply-chain integrity, policy enforcement. |
| Security Engineer | Trust boundaries, threat model currency, secret handling. |
| Application Developer | Future workload owner — deploys onto the platform, doesn't build it. |
| Platform Administrator | Day-2 operator; reaches the cluster only via ZTNA. |
| SRE / Incident Responder | Observability signal quality, runbooks, rollback paths. |
| Autonomous Engineering Agent | The primary consumer of the issue backlog — needs each issue to be self-contained. |
