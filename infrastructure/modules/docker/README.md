# Docker Module

Provisions containers, networks, and volumes on Docker-compatible hosts (Docker Desktop,
OrbStack, etc.) via the Terraform Docker provider.

## Module Contract

### Required Inputs

None — all inputs have sensible defaults.

### Optional Inputs

| Input | Type | Default | Description |
| ------- | ------ | --------- | ------------- |
| `docker_socket_path` | string | `unix:///Users/guillermolam/.orbstack/run/docker.sock` | Docker socket URI for OrbStack or local Docker |
| `image_name` | string | `alpine:latest` | Docker image (e.g., `postgres:16-alpine`) |
| `container_name` | string | `app` | Container name (1-63 chars, unique per host) |
| `container_memory_mb` | number | `512` | Memory limit in MB (0 = unlimited) |
| `container_cpu_shares` | number | `0` | CPU shares (1024 = 1 CPU, 0 = unlimited) |
| `port_mappings` | list(object) | `[]` | Port mappings: `{internal=5432, external=5432, protocol="tcp"}` |
| `environment_vars` | map(string) | `{}` | Environment variables passed to container |
| `volume_mounts` | list(object) | `[]` | Volume mounts: `{host_path="/data", container_path="/data", read_only=false}` |
| `network_mode` | string | `"bridge"` | Network mode: `bridge`, `host`, or `none` |
| `network_name` | string | `"app-network"` | Docker network name (when network_mode = "bridge") |
| `network_driver` | string | `"bridge"` | Network driver: `bridge` or `overlay` |
| `network_cidr` | string | `""` | CIDR block for custom network (e.g., `172.20.0.0/16`) |
| `restart_policy` | string | `"unless-stopped"` | Restart policy: `no`, `always`, `unless-stopped`, `on-failure` |
| `privileged` | bool | `false` | Run in privileged mode (dangerous, use with caution) |
| `tags` | map(string) | `{environment="lab", owner="platform"}` | Resource labels |

### Outputs

| Output | Type | Description |
| -------- | ------ | ------------- |
| `container_id` | string | Full container ID |
| `container_name` | string | Container name |
| `image_id` | string | Docker image ID |
| `image_repo_digest` | string | Image repository digest (if available) |
| `network_id` | string | Docker network ID (if created) |
| `network_name` | string | Docker network name (if created) |
| `container_ports` | list(object) | Exposed port mappings |
| `container_status` | number | Container exit code (0 = running) |

## Assumptions

1. **Docker Socket Access**: Host has access to Docker socket at configured path
2. **OrbStack (if used)**: Running on macOS with Apple Silicon, socket at `~/.orbstack/run/docker.sock`
3. **Network Isolation**: Bridge networks are isolated from host network by default
4. **Volume Permissions**: Host paths have correct ownership/permissions for container access
5. **Image Availability**: Docker image exists or is publicly available (will be pulled)

## Known Limitations

1. **Swarm Services**: Module does not support Swarm-mode services (standalone containers only)
2. **Health Checks**: Health checks are not configured (can be added via `docker_container` lifecycle)
3. **Secrets Management**: Sensitive environment variables are stored in Terraform state (use OpenBao/Vault in production)
4. **No Named Volumes**: Module uses bind mounts only (named volumes can be added via `docker_volume` resource)
5. **Socket Path Required**: Docker socket path must be explicitly configured for non-standard environments

## Usage Example

```hcl
module "postgres" {
  source = "../../../modules/docker"

  image_name     = "postgres:16-alpine"
  container_name = "homelab-db"

  port_mappings = [
    { internal = 5432, external = 5432, protocol = "tcp" }
  ]

  environment_vars = {
    POSTGRES_DB       = "homelab"
    POSTGRES_PASSWORD = "secure-password"
  }

  volume_mounts = [
    { host_path = "/data/postgres", container_path = "/var/lib/postgresql/data", read_only = false }
  ]

  network_name = "homelab-net"
  tags = {
    environment = "lab"
    component  = "database"
  }
}
```

## Provider Configuration

This module does **not** declare a provider block. Provider configuration is generated by Terragrunt's `root.hcl`:

```hcl
generate "provider" {
  path      = "provider.tf"
  if_exists = "overwrite_terragrunt"
  contents  = <<-EOF
provider "docker" {
  host = var.docker_socket_path
}
EOF
}
```

This pattern follows the established Terragrunt composition layer governance (ADR-0001).
